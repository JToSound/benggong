## 1. 設計：故事時間 vs 首次提及

### 1.1 核心模型

一條條目 = **故事世界入面嘅一件事**，帶兩個時間軸：

| 欄位 | 意思 |
|---|---|
| `story_time` | 件事**幾時發生**（故事內時間） |
| `first_mention_chapter` | 讀者**幾時第一次知** |
| `flashback` | 兩者唔同 → `true`（即係「回帶」） |

**兩者唔同就係編年史嘅價值所在** —— 用戶原話：「有啲內容可能喺後續嘅
篇章先會回帶返過去，去補完先前嘅伏筆」。

### 1.2 六個時期

| 代號 | 名稱 | 意思 |
|---|---|---|
| `pre_outbreak` | 爆發前 | 病毒未爆發（角色過去） |
| `outbreak` | 病毒爆發 | 爆發嘅當下 |
| `early` | 爆發初期 | 頭幾個月，社會崩潰中 |
| `basecamp` | 大本營時期 | 調景嶺校園聚居地 |
| `lohas` | 康城時期 | 康城／日出康城，或後期其他倖存區 |
| `endgame` | 終局 | 最後階段，大決戰 |

⚠️ 用戶選擇「按**時期**（唔用日期）」——因為小說冇明確日曆。

### 1.3 UI

| 功能 | 說明 |
|---|---|
| 視覺隱喻 | **檔案館嘅時間軸**：左側垂直線串起時期，事件卡喺右邊 |
| 時期分組 | 6 個時期，逐組展開 |
| 回帶標記 | 紫色左邊框 + `↩` |
| 章節標籤 | 每條列出所有相關章節，可點擊跳去 |
| **伏筆連結** | 「→ 埋下伏筆」「↩ 解答咗」，**可點擊跳轉** |
| 模式切換 | 頂欄「📜 編年史 / 📖 章節」 |
| 章節條 | 由「切換章節」改為**篩選器**（用戶選擇） |

## 3. 關鍵發現

### 3.1 ⚠️ LLM 逐條判斷有**系統性錯誤**

階段 2 嘅 LLM 只睇標題 + 150 字摘要，缺乏章節上下文。抽樣核實：

| 章節 | 內容 | LLM 判 | 實際 |
|---|---|---|---|
| ch89 | 病腦大廚煮童（不良人 arc） | 康城時期 ✗ | **大本營** |
| ch77 | 病童哀哭聲、刀具架 | 康城時期 ✗ | **大本營** |
| ch113 | 莎士比亞違禁品、**艾寶琳共和國** | 大本營時期 ✗ | **康城** |

**一致率只有 67.8%**（823 一致／391 分歧）→ 階段 3 修正 **391 條**。

### 3.2 故事喺地點上係**非線性**嘅

角色喺「大本營」同「艾寶琳／康城」之間**來回走動**：

```
ch141-144 大本營 → ch145-147 艾寶琳 → ch148-150 大本營 → ch151-160 康城
```

**時期唔可以當成單調遞進** —— 呢個係抽樣版本睇唔到嘅。

### 3.3 抽樣不足以定邊界

階段 2 抽樣 24 章得出「爆發初期 1–15」，但逐章審視顯示
**ch3 就已經進入大本營**。→ 當時**拒絕硬套**係正確嘅保守決定。

## 7. 已知限制

1. **時期邊界係啟發式** —— 由 10 個代理逐章判定，非人手覆核。
   個別章節（例如 ch98 單期 `lohas`、ch169 錄影回帶）可能有爭議。

2. **伏筆關係只有 85 對** —— 相對 1,320 條條目，覆蓋率低。
   代理被要求「寧缺勿濫」，所以偏向保守。

3. **合併可能過度** —— 396 條合併（23%）係由代理建議，未經人手覆核。
   最大組 8 條事件、最多跨 6 章。

4. **未做嘅功能**：
   - 章節內事件排序（目前只有章節級）
   - 事件喺地圖上嘅空間分佈（只有文字地點）

## 8. 教訓（可復用）

1. **腳本必須冪等** —— 若處理步驟會「重建」而非「增量」，任何
   「按當前狀態過濾」嘅前置步驟都會令重跑**靜默倒退**。

2. **前後端 enum 必須同步** —— 新增 `source` 值要同步更新前端判斷，
   否則資料「有但唔顯示」。**已加測試保護**。

3. **抽樣不足以定邊界** —— 逐章審視才準。抽樣會遺漏章節級嘅跳躍。

4. **子代理輸出要持久化** —— 訊息傳遞會因中斷而遺失（A1 嘅 24 組
   就係咁失去，要重新要求）。未來應要求同時寫入檔案。

5. **驗證機制嘅價值** —— 重跑時 `id not in entries` 檢查攔截咗
   A3 嘅 94 組（已套用過），避免錯誤合併。

6. **子代理嘅發現可以係對嘅，但必須親自核實** —— agent-1 指出 2 條
   回帶修正，我一度因為比較錯欄位（`chapter_num` vs `issue_index`）
   而想拒絕，核實原文後證實佢係對嘅。
